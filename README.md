# Lab 02 - Registro de Matrícula en Kotlin

Programa de consola desarrollado en Kotlin para gestionar el registro de cursos de un estudiante. Calcula el costo total por crédito, evalúa la carga académica y determina el esquema de pago en cuotas.

## Funcionalidades
* **Ingreso de datos:** Lectura del nombre del estudiante, cantidad de cursos y valor por crédito.
* **Cálculo de totales:** Sumatoria interactiva de créditos y costo por materia.
* **Evaluación de reglas:** Determinación de carga académica (M.R., Carga Completa, Req. Autoriz.) y cálculo de cuotas (2 o 3 pagos).
* **Reporte final:** Impresión formateada del resumen de matrícula.
